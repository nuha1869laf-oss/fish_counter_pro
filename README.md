# fish_counter_pro
# 🐟 AI Fish Counter

AI-based fish detection, counting and tracking web application using Flask and computer vision.

## Features

- Fish image upload
- Fish detection and counting
- Video fish detection and tracking
- Camera capture
- Result display

## Requirements

- Python
- Flask
- Required Python packages from `requirements.txt`
- Roboflow API key

## How to Run

1. Clone or download this repository.
2. Open the project folder in Command Prompt.
3. Install the required packages:

```bash
pip install -r requirements.txt
```

4. Configure the Roboflow API key.

5. Run the Flask application:

```bash
python app.py
```

6. Open the displayed local URL in a web browser.
